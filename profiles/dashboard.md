# Profile: Dashboard

Apply: ARCHITECTURE, DEPENDENCIES, SECURITY, PERFORMANCE, TESTING, API, CONFIGURATION, OBSERVABILITY, RELIABILITY, DOCUMENTATION, RELEASES, GIT_AND_PRS, REPOSITORY_HYGIENE, DEPLOYMENT, LICENSING_IP, and AGENT_BEHAVIOR, plus the relevant backend language standards.

Additional requirements:
- define consistent loading, empty, degraded, error, and success states;
- use responsive and keyboard-accessible interaction patterns;
- avoid hard-coded environment-specific endpoints;
- keep expensive polling bounded and configurable;
- use server push or adaptive refresh only when it materially improves behavior;
- prevent charts/tables from rendering unbounded historical data by default;
- expose source freshness and unavailable/stale states instead of presenting stale values as live;
- test representative user workflows and failure states.
