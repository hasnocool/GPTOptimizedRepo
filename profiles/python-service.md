# Profile: Python Service

Apply: PYTHON, ASYNC_PYTHON, ARCHITECTURE, DEPENDENCIES, SECURITY, PERFORMANCE, TESTING, API, DATABASE when applicable, CONFIGURATION, OBSERVABILITY, RELIABILITY, DOCUMENTATION, RELEASES, GIT_AND_PRS, REPOSITORY_HYGIENE, DEPLOYMENT, LICENSING_IP, and AGENT_BEHAVIOR.

Additional requirements:
- explicit startup/readiness/shutdown lifecycle;
- bounded concurrency and connection pools;
- health/readiness endpoints where appropriate;
- request/job correlation identifiers;
- graceful cancellation and restart-safe background work;
- no blocking I/O on the event loop.
