# Licensing and IP Governance

- Every dependency and copied code fragment must be compatible with the repository's license and intended distribution model.
- Preserve required notices and attribution.
- Prefer SPDX identifiers in package metadata and generated artifacts where supported.
- Do not copy substantial code from unknown or incompatible sources.
- Record provenance when incorporating externally derived code, datasets, models, prompts, or assets that impose material obligations.
- Generated code must still be reviewed for accidental reproduction of incompatible licensed material or embedded credentials.
- New dependencies with copyleft, source-available, non-commercial, or otherwise restrictive terms require explicit review before adoption.
- Keep third-party notices current for distributed artifacts when required.
