# GPTOptimizedRepo v0.1.0

First public release of GPTOptimizedRepo.

## Highlights

- Establishes `AGENTS.md` as the canonical shared repository policy for coding agents.
- Adds compatibility and project guidance for Codex, OpenCode, OpenClaude/Claude, Pi, Oh My Pi, and Prime Intellect.
- Documents a durable ChatGPT Project + GitHub workflow for development, research, and project memory.
- Adds Codex implementation guidance and Deep Research workflow documentation.
- Adds Scheduled Tasks guidance for recurring and conditional monitoring.
- Adds repository operating documents including `README.md`, `TODO.md`, and `CHANGELOG.md`.

## Agent compatibility

- Codex: root `AGENTS.md`
- OpenCode: root `AGENTS.md` plus `opencode.json`
- OpenClaude / Claude-style agents: `CLAUDE.md` delegating to `AGENTS.md`
- Pi: root `AGENTS.md`
- Oh My Pi: `.omp/AGENTS.md` and `.omp/RULES.md`
- Prime Intellect: root `AGENTS.md` plus `.prime/skills/repo-governance/SKILL.md`

## Purpose

GPTOptimizedRepo is a reference repository for using ChatGPT Plus and multiple coding-agent harnesses around a single durable GitHub source of truth. Conversations remain the working interface while repository files retain project policy, implementation context, research findings, and operational guidance.
